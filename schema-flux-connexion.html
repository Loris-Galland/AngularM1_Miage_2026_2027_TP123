TP1 — Mission 0

Flux de connexion, clic par clic

Ce qui se passe entre le moment où je clique sur « Se connecter » sur /login et le moment où j'arrive sur /tracks, dans Guitar Practice Cloud.

1

Je remplis le formulaire et je clique

login-page.html

Le formulaire réactif est lié à form dans LoginPageComponent. Le clic déclenche (ngSubmit)="submit()".

2

Le composant lit le formulaire

LoginPageComponent.submit()

Récupère email/password, puis délègue tout à AuthService — le composant n'appelle jamais HttpClient directement.

this.auth.login(values.email, values.password).subscribe({ ... })
3

Le service construit la requête

AuthService.login()

this.http.post('/api/auth/login', { email, password })
4

L'intercepteur JWT passe la main

authInterceptor

Route publique donc pas de token encore requis — l'intercepteur laisse la requête filer sans en-tête Authorization (ou avec un ancien token que le backend ignore ici).

5

La requête sort du navigateur

proxy.conf.json (dev)

/api/* → http://localhost:3000
6

Le backend vérifie l'utilisateur

backend · route POST /api/auth/login

Cherche l'utilisateur en base via Mongoose, compare le mot de passe avec bcrypt.compare. Si tout est bon : jwt.sign() génère le token avec JWT_SECRET.

7

La réponse remonte et met à jour l'état

AuthService.login() → tap(storeAuthentication)

localStorage.setItem('gpc_token', token) token.set(token) currentUser.set(user)

Les deux Signals (token, currentUser) sont mis à jour — toute l'appli qui les lit se met à jour automatiquement.

8

Le composant réagit au résultat

LoginPageComponent.submit() · callbacks subscribe

Selon que l'appel a réussi ou échoué, deux chemins possibles ↓

Bifurcation

✓ Succès

next() s'exécute

router.navigateByUrl('/tracks')

Je suis redirigé, connecté.

✕ Échec

error() s'exécute

error.set(message)

Le message s'affiche sous le formulaire, je reste sur /login.
